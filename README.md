# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3192 |
| 应用 | http://localhost:8192 |
| PostgreSQL | localhost:54392 |

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 出样打印队列

审评台通过行可排入出样打印队列。入队时**冻结**当时的批次、香气/滋味/汤色三项分、加权分、结论原文并生成队列号；之后改正审评三项分只影响审评台，不改已入队正文。顶栏「出样打印队列」进入专页，按队列号倒序；正文页可由审评员「标记已打印」。

- 未通过行禁止入队（服务端返回 403，页面无入队按钮）。
- 入队、改正三项分、标记已打印仅审评员（taster）可操作；观察员（observer）只读队列。
- 每条审评记录最多入队一次。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过；春茶-A 有「排入出样队列」，夏茶-C 显示禁止入队。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交、改正、入队、标记打印入口，只能浏览队列。
4. 春茶-A 入队后改正滋味（8→9，加权分 7.8→8.3），打开该队列正文，三项分与加权分仍是入队时的 8、7.8。
5. 夏茶-C 尝试入队被拒（403），不生成队列号。
