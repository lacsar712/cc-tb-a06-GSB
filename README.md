# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3192 |
| 应用 | http://localhost:8192 |
| PostgreSQL | localhost:54392 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|

| observer | look123456 | 只看 |

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 出样打印队列

- 通过行可由审评员「排入出样队列」；入队时冻结当时的批次、香气/滋味/汤色、加权分与结论原文，生成自增队列号。
- 审评员可随时改正三项分（服务端重算加权分与结论），但已入队正文保持入队时的快照不变。
- 未通过行禁止入队（含重复入队拦截）。
- 顶栏「出样队列」专页按队列号倒序展示冻结正文；「标记已打印」仅审评员可点，观察员对队列只读。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单，也看不到改正、入队、打印按钮。
4. 春茶-A 入队后改正滋味使其翻为不通过，打开出样队列，该条正文的加权分与结论仍是入队时的数。
5. 夏茶-C（不通过）尝试入队被拒（400）；观察员对入队/改正/打印的写操作均被拒（403）。
